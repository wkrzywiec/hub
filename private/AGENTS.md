# private

Personal apps and local infrastructure. Each subfolder is a separate git repo.

- `mankkoo/` - personal finance dashboard (Flask backend, Next.js frontend, PostgreSQL).
- `local-postgres/` - shared local PostgreSQL (pgvector), pgAdmin and Infisical used by other projects.
- `newsletters-triage/` - Python CLI that triages newsletters and generates HTML digests.

Treat contents as private; do not publish or copy data out of these repos.
